# 杜氏麻雀

清酒造りの工程を牌にした4人麻雀です。相手はCPU3人。ポン・チー・ロンがあり、東風戦の4局で終わります。

遊ぶ: https://y-kanno-sakenote.github.io/toji-mahjong/

## 牌（34種×4枚＝136枚）
- 数牌：3つのタンク（紅・緑・藍）×1〜9。数字は工程の順です：1精米 2洗米 3浸漬 4蒸し 5製麹 6酒母 7初添 8仲添 9留添（杜氏ソリティアと同じ番号）
- 風牌：上槽・濾過・火入れ・貯蔵
- 三元牌：米・米こうじ・水
- タンクの色に醸造上の意味はありません

## 遊び方
- 上がりは、3枚の組×4と同じ牌2枚。組は「同じ牌3枚」か「同じ色の続き番号3枚」です
- 役がなくても上がれます。カン・リーチ・ドラはありません
- 役は「三段仕込み（7・8・9）」「原料処理（1〜4）」「清酒の原料（米・米こうじ・水）」など。画面の「役」で一覧が見られます
- 記録（1位の回数・最高点）はこの端末の中だけに残します（どこにも送りません）
- 音はブラウザの中で合成しています。🔈で消せます

## 素材と出典
- 工程の名前とまとまりは、『日本酒の基』（日本酒サービス研究会・酒匠研究会連合会）の製法と歴史の章、国税庁「日本の伝統的なこうじ菌を使った酒造り」をもとに、自分の言葉でまとめました。「清酒の原料」の説明は酒税法の清酒の定義によります
- 工程の記号は杜氏ソリティアと共通の自作です
